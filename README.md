# line-following-car

STM32F103C8T6（Blue Pill）+ L298N 的双轮循迹小车。用 Arduino 框架，PlatformIO 构建。

两个 TCRT5000 循迹探头骑跨在黑线两侧，哪个探头压到黑线就往那一侧修方向。

## 接线

| 功能 | 引脚 | 说明 |
| --- | --- | --- |
| L298N IN1 | PB6 | TIM4_CH1，左轮 |
| L298N IN2 | PB7 | TIM4_CH2，左轮 |
| L298N IN3 | PB8 | TIM4_CH3，右轮 |
| L298N IN4 | PB9 | TIM4_CH4，右轮 |
| 循迹 RO | PB12 | 右侧探头 |
| 循迹 LO | PB13 | 左侧探头 |
| 板载 LED | PC13 | 低电平点亮 |
| 串口 | PA9 / PA10 | 调试用，115200 |

- L298N 的 **ENA、ENB 跳线帽保持短接**，速度靠 IN 脚上的 PWM 实现。
- 电机 A 接 OUT1/OUT2（左轮），电机 B 接 OUT3/OUT4（右轮）。
- L298N 的 12V 接电池，5V 输出可以给 Blue Pill 供电，**GND 必须和板子共地**。
- 循迹模块 VCC 接 5V、GND 共地、RO/LO 接 PB12/PB13。PB12/PB13 是 F103 上的
  5V 容忍脚，模块输出 5V 可以直接接。
- 两个探头装在前端左右两侧，间距略大于黑线宽度（让黑线从两个探头中间穿过），
  探头离地 5~15mm。

## 编译和烧写

```bash
pio run              # 编译
pio run -t upload    # 用 ST-Link 烧写
pio device monitor   # 看串口（调试模式用）
```

下载器不是 ST-Link 时，改 `platformio.ini` 里的 `upload_protocol`。

## 第一次上车，按这个顺序调

1. **架起来试**（轮子悬空）。上电后板载 LED 常亮 1 秒，然后两个轮子同时往前转，
   之后 LED 每 500ms 短闪一下。
2. 哪个轮子反转，就对调代码里**该侧**两个 `IN` 常量。
3. 左右两轮互换，就对调 `LEFT_IN*` 和 `RIGHT_IN*` 两组常量。
4. **确认探头极性**：把 `TRACK_DEBUG` 改成 `1` 再烧一遍，接串口，探头放到黑线上看
   打印里 `black LO=1 RO=0` 之类的结果对不对。反了就把 `TRACK_BLACK_IS_HIGH` 取反。
   调试模式下电机不转，可以放心拿着车在线上划。
5. 落地跑。`BASE_SPEED` 从 120 开始往上加。
6. 车画龙、转得太猛：把 `TURN_INNER` 调大、`TURN_OUTER` 调小；
   反应太慢跟不上线：反过来调。

## 控制逻辑

两个探头都压在白底上（黑线从中间穿过）时直行：

| LO | RO | 含义 | 动作 |
| --- | --- | --- | --- |
| 白 | 白 | 正常骑跨在线两侧 | 直行 |
| 黑 | 白 | 线偏到左边，车偏右了 | 左轮慢、右轮快（向左修） |
| 白 | 黑 | 线偏到右边，车偏左了 | 左轮快、右轮慢（向右修） |
| 黑 | 黑 | 十字路口或宽线 | 直行 |

如果实测发现车越修越偏，说明左右装反了，对调 `TRACK_LO` / `TRACK_RO` 两个常量。

## 可调参数

都在 `src/main.cpp` 顶部：

| 参数 | 作用 |
| --- | --- |
| `TRACK_BLACK_IS_HIGH` | 探头压黑线时输出高电平就设 `true` |
| `BASE_SPEED` | 直行速度，0~255 |
| `TURN_OUTER` | 转弯时外侧轮速度 |
| `TURN_INNER` | 转弯时内侧轮速度，越小转得越急 |
| `RAMP_STEP` | 每个控制周期最多变速多少，防止起步顿挫和打滑 |
| `PERIOD_MS` | 控制周期，默认 10ms |
| `DEBOUNCE_SAMPLES` | 探头去抖次数 |
| `ARM_DELAY_MS` | 上电后等多久才开动，用来摆车 |
| `TRACK_DEBUG` | `1` = 只打印探头状态、电机不转 |

## 常见问题

- **电机不转，但 LED 在闪**：检查 ENA/ENB 跳线帽、电池电压、L298N 与板子的 GND 是否共地。
- **上电就乱转一下**：同样先查共地；代码里已经先把四路 IN 拉低再延时开动。
- **车原地打转**：探头极性反了（第 4 步），或者 LO/RO 接反了。
- **跑到线的尽头冲出去**：正常。两个探头都看不到黑线时，程序按"直行"处理。
- **电机叫声刺耳**：PWM 默认 1kHz。想把声音挪开人耳范围，把 `setup()` 里的
  `analogWriteFrequency(20000);` 取消注释，L298N 支持，只是发热会略增。
- PB6/PB7 也是 I2C1 的 SCL/SDA，这套接线里已经占用了，以后加 I2C 屏幕要换别的脚。
